# Celcom Platform — UI Kit (SaaS)

Panel omnicanal de Celcom. Basado en los componentes SaaS del design-system.jsx.

## Componentes
- `Sidebar.jsx` — nav lateral azul profundo con grupos.
- `Topbar.jsx` — header del panel con búsqueda + avatar.
- `Dashboard.jsx` — KPIs + usage meters + status + banner.
- `CampaignsTable.jsx` — tabla de campañas con estado y acciones.
- `WhatsAppInbox.jsx` — inbox estilo chat.

`index.html` arma el panel con navegación entre secciones.
