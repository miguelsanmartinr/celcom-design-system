# Celcom Website — UI Kit

Recreación hi-fi del sitio corporativo **celcomlatam.com**. Landing + sections del sitio marketing, basado en la captura PDF y el design system (`celcom-design-system.jsx`).

## Componentes
- `Header.jsx` — nav blanco con CTA amarillo "Compra de créditos SMS".
- `Hero.jsx` — banda azul con headline + ilustración flotante de blobs.
- `QuienesSomos.jsx` — sección "¿Quiénes somos?" con collage de imágenes y descripción.
- `PromesaBanner.jsx` — banda azul o amarilla con claim de compromiso (usado x2 en la home).
- `ServiciosTabs.jsx` — tabs verticales (WhatsApp API / SMS Masivo / Email / Chatbot) con preview a la derecha.
- `SolucionesGrid.jsx` — 4 cards de solución (Marketing, Ventas, Atención, Tecnología).
- `ClientesCarousel.jsx` — strip de logos de clientes con flechas amarillas.
- `TestimonioSlider.jsx` — banda azul con testimonio + logo + autor.
- `Formulario.jsx` — form dentro de un card azul profundo.
- `ChatWidget.jsx` — asistente comercial flotante.
- `Footer.jsx` — azul profundo con links, socials, banderas LATAM.

## Screens
- `index.html` carga una "home completa" scrolleable, reutilizando los componentes.
