Read the README.md file within this skill, and explore the other available files.

If creating visual artifacts (slides, mocks, throwaway prototypes, etc), copy assets out and create static HTML files for the user to view. If working on production code, you can copy assets and read the rules here to become an expert in designing with this brand.

If the user invokes this skill without any other guidance, ask them what they want to build or design, ask some questions, and act as an expert designer who outputs HTML artifacts _or_ production code, depending on the need.

Key files:
- `README.md` — company context, voice & tone, visual foundations, iconography.
- `colors_and_type.css` — CSS variables for colors, type scale, spacing, radii, shadows + semantic styles.
- `assets/` — logos (SVG + app icon), channel SVG icons, background patterns.
- `ui_kits/website/` — marketing site recreation (hero, servicios tabs, formulario, footer).
- `ui_kits/platform/` — SaaS panel (sidebar, dashboard, campaigns, WhatsApp inbox).
- `preview/` — small spec cards (colors, type, components) used by the Design System tab.

Brand in one line: **Celcom is a Chilean omnichannel messaging platform (SMS, WhatsApp API, Email, Chatbots)**. Primary is deep blue `#0057B8`, secondary is navy `#001F5B`, accent is yellow `#FFB800`. Poppins for headings, Inter for body. Spanish (Chilean), warm professional "tú".
